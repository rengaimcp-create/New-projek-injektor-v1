# KAKORO INJECTOR — Native Android Floating Panel

Kotlin + Jetpack Compose project for Android 8.0+ (API 26+), package `com.emeng.proxxy`. The floating panel can be dragged, minimized, closed, and can launch the installed Free Fire app (`com.dts.freefireth`).

## Included
- Native Android app; no virtual machine, virtual space, root, Shizuku, or ADB Wi-Fi required for ordinary overlay use.
- Floating panel titled **KAKORO INJECTOR** with the requested feature labels: SHOW GHOST, SHOW FREEZE, SHOW TUNEL, ESP LINE, ESP BOX, ESP SKELETON, ESP ENEMY, RADAR, CROSSHAIR, ESP COLOR, TEMA COLOR, ICON (SS00), NEW BYPASS.
- Local visual toggles, movable panel, minimize/close buttons, and launch-game action.
- Existing local crosshair studio, local presets, device information, and training arena.

## Important limits
The named ESP and bypass switches are UI/demo toggles only. They do not read game memory, inject code, reveal enemy positions, automate aiming, or bypass anti-cheat. No safety/undetected guarantee is made. Android overlay permission must be granted manually. Compatibility depends on the device and installed Free Fire package.

## Build
Open this folder in Android Studio with JDK 17 and let Gradle sync. Then use **Build > Build APK(s)**. This source archive does not include a Gradle wrapper and has not been compiled in this environment.
